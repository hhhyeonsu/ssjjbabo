JSON 데이터 백업 및 복원

시스템의 모든 데이터(현장 목록, 물량 산정 내역, 공휴일 기준)를 JSON 파일로 다운로드하거나, 이전에 백업한 파일을 불러와 복원할 수 있습니다.

스토리지 무결성 및 캐시 안내

• 브라우저의 캐시나 인터넷 사용 기록을 완전히 삭제하면 등록된 프로젝트 및 물량 데이터가 지워질 수 있으므로 정기적으로 [데이터 JSON 내보내기]를 실행해 백업해 두는 것을 권장합니다.

• 초기화 버튼 클릭 시 `seed.js`에 정의된 기본 예시 데이터로 즉시 복원됩니다.
